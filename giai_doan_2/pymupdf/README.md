Nếu pdfplumber mạnh về trích xuất text/table, thì PyMuPDF (fitz) là thư viện toàn diện hơn rất nhiều:

✅ Đọc text cực nhanh
 ✅ Trích xuất ảnh
 ✅ Render PDF thành ảnh
 ✅ Highlight/Annotate PDF
 ✅ Chỉnh sửa PDF
 ✅ Tách/Gộp PDF
 ✅ OCR workflow
 ✅ RAG và Document AI

Đối với các dự án AI hiện nay, mình thường dùng:

PyMuPDF
    ↓
Text + Layout + Images
    ↓

    ↓

    ↓
Vector DB

13. Trích xuất ảnh từ PDF

Ví dụ PDF chứa logo hoặc hình minh họa.

for page_num in range(len(doc)):

    page = doc[page_num]

    images = page.get_images()

    print(images)

Lưu ảnh
for page_index in range(len(doc)):

    page = doc[page_index]

    images = page.get_images(full=True)

    for img_index, img in enumerate(images):

        xref = img[0]

        base_image = doc.extract_image(xref)

        image_bytes = base_image["image"]

        image_ext = base_image["ext"]

        with open(
            f"img_{page_index}_{img_index}.{image_ext}",
            "wb"
        ) as f:
            f.write(image_bytes)

21. Chuyển PDF thành Markdown cho RAG

Đây là use case rất phổ biến.

import fitz

doc = fitz.open("manual.pdf")

content = []

for page_num, page in enumerate(doc):

    text = page.get_text()

    content.append(
        f"# Page {page_num+1}\n\n{text}"
    )

markdown = "\n\n".join(content)

with open(
    "manual.md",
    "w",
    encoding="utf-8"
) as f:
    f.write(markdown)

24. Ví dụ thực tế cho VinFast RAG

Mình khuyến nghị cấu trúc như sau:

import fitz

doc = fitz.open("vehicle_manual.pdf")

documents = []

for page_num, page in enumerate(doc):

    blocks = page.get_text("blocks")

    for block in blocks:

        documents.append({
            "page": page_num + 1,
            "bbox": block[:4],
            "content": block[4]
        })


Output:

[
 {
   "page": 5,
   "bbox": [50,100,400,150],
   "content": "Battery temperature..."
 }
]


Sau đó:

PyMuPDF
    ↓
Block Level Chunking
    ↓
Embedding
    ↓
Azure AI Search
    ↓
Citation bằng trang + bbox
